# Solana Sniper Bot

Бот для автоматического мониторинга и торговли новыми токенами на Raydium DEX в сети Solana.

## ⚠️ ВАЖНО: Безопасность

**НИКОГДА не сохраняйте приватный ключ в конфигурационных файлах или коде!**

Этот бот использует файл `.env` для безопасного хранения приватного ключа. Убедитесь, что:
- Файл `.env` добавлен в `.gitignore`
- Никогда не коммитите `.env` файл в репозиторий
- Храните резервную копию приватного ключа в безопасном месте

## Возможности

- Мониторинг новых пулов ликвидности на Raydium
- Автоматическая покупка токенов при соответствии заданным критериям
- Автоматическая продажа токенов при достижении целевой прибыли или стоп-лосса
- Ручное управление через командную строку
- Настраиваемые параметры фильтрации токенов
- Отслеживание портфеля и рентабельности

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/username/solana-sniper-bot.git
cd solana-sniper-bot

# Установка зависимостей
npm install

# Создание .env файла из примера
cp .env.example .env

# Редактирование .env файла и добавление вашего приватного ключа
nano .env  # или используйте любой текстовый редактор

# Создание глобальной команды (опционально)
npm link
```

## Настройка

### 1. Создание .env файла

Создайте файл `.env` в корне проекта со следующим содержимым:

```
# Solana wallet private key (base58 format)
SOLANA_PRIVATE_KEY=ваш_приватный_ключ_здесь

# Network configuration (optional)
SOLANA_NETWORK=mainnet-beta
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
```

### 2. Альтернативные RPC ноды (рекомендуется)

Для лучшей производительности рекомендуется использовать приватные RPC ноды:

- **Quicknode**: https://www.quicknode.com/
- **Alchemy**: https://www.alchemy.com/
- **Ankr**: https://www.ankr.com/
- **Project Serum**: https://solana-api.projectserum.com

## Использование

### Инициализация бота

```bash
node index.js init
# или если установлена глобальная команда
solsniper init
```

Если приватный ключ не найден в `.env` файле, бот попросит ввести его во время инициализации.

### Настройка параметров

```bash
node index.js config
# или
solsniper config
```

Настраиваемые параметры:
- **Максимальный налог на покупку/продажу**: Фильтр для токенов с высокими комиссиями
- **Минимальная ликвидность**: Минимальный объем ликвидности в SOL
- **Сумма для покупки**: Количество SOL для покупки каждого токена
- **Автопродажа**: Процент прибыли для автоматической продажи
- **Стоп-лосс**: Процент убытка для автоматической продажи
- **Проскальзывание**: Допустимое проскальзывание цены
- **Автопокупка**: Включить/выключить автоматическую покупку

### Запуск бота

```bash
node index.js start
# или
solsniper start
```

### Быстрый снайпинг (рекомендуется для тестирования)

```bash
node index.js snipe-new --time 5 --amount 0.01 --min-liquidity 0.1
# или
solsniper snipe-new -t 5 -a 0.01 -l 0.1
```

Параметры:
- `--time, -t`: Время мониторинга в минутах (по умолчанию: 5)
- `--amount, -a`: Сумма для покупки в SOL (по умолчанию: 0.005)
- `--min-liquidity, -l`: Минимальная ликвидность в SOL (по умолчанию: 0.05)

### Проверка токена

```bash
node index.js check-token <адрес_токена>
# или
solsniper check-token <адрес_токена>
```

### Ручная покупка токена

```bash
node index.js buy <адрес_токена> <количество_sol>
# или
solsniper buy <адрес_токена> <количество_sol>
```

### Ручная продажа токена

```bash
node index.js sell <адрес_токена> [процент]
# или
solsniper sell <адрес_токена> [процент]
```

По умолчанию продается 100% баланса токена.

### Отслеживание новых пулов ликвидности

```bash
node watch-liquidity.js
```

Скрипт будет каждые несколько секунд проверять Raydium на появление новых пулов
и выводить адрес токена, для которого добавлена ликвидность. Если API Raydium
недоступен, используются демонстрационные данные.

### Просмотр портфеля

```bash
node index.js portfolio
# или
solsniper portfolio
```

## Структура проекта

- `index.js` - Точка входа и CLI-интерфейс
- `config.js` - Управление конфигурацией

## ⚠️ Предупреждения

1. **Безопасность**: 
   - Никогда не делитесь своим приватным ключом
   - Не сохраняйте приватный ключ в коде или конфигурационных файлах
   - Используйте отдельный кошелек для бота с ограниченными средствами

2. **Риски торговли**:
   - Торговля криптовалютами связана с высоким риском
   - Новые токены особенно рискованны (rug pulls, honeypots)
   - Используйте только те средства, которые готовы потерять

3. **Технические ограничения**:
   - Бот использует mock данные если API Raydium недоступен
   - Функции свапа в текущей версии являются фиктивными
   - Требуется реальная интеграция с Raydium SDK для production

## Рекомендации по безопасности

1. **Используйте отдельный кошелек**:
   ```bash
   # Создайте новый кошелек специально для бота
   solana-keygen new --outfile ~/bot-wallet.json
   ```

2. **Ограничьте средства**:
   - Держите на кошельке бота только необходимую сумму
   - Регулярно выводите прибыль на основной кошелек

3. **Мониторинг**:
   - Следите за логами бота
   - Проверяйте транзакции на Solscan
   - Установите уведомления о больших движениях средств

4. **Тестирование**:
   - Сначала протестируйте на devnet
   - Начните с минимальных сумм на mainnet
   - Постепенно увеличивайте объемы

## Известные проблемы

1. **API Raydium**: Официальное API может быть недоступно или изменено
2. **Фиктивные транзакции**: Текущая версия не выполняет реальные свапы
3. **Оценка налогов**: Методы оценки налогов возвращают фиксированные значения
