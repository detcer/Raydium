# Устранение неполадок (Troubleshooting)

## Частые проблемы и их решения

### 1. Ошибка: "Приватный ключ не найден"

**Проблема**: При запуске команд появляется сообщение об отсутствии приватного ключа.

**Решение**:
1. Убедитесь, что файл `.env` существует в корне проекта
2. Проверьте, что в `.env` файле есть строка `SOLANA_PRIVATE_KEY=ваш_ключ`
3. Запустите `node index.js init` для повторной инициализации

### 2. Ошибка: "Отсутствует адрес токена (token_mint)"

**Проблема**: При запуске бота появляются предупреждения о некорректных данных пулов.

**Причина**: API Raydium недоступен или изменился формат данных.

**Решение**:
- Бот автоматически переключится на mock данные для тестирования
- Для работы с реальными данными потребуется обновление интеграции с Raydium

### 3. Ошибка подключения к Solana

**Проблема**: "Не удалось подключиться к сети Solana"

**Решения**:
1. Проверьте интернет-соединение
2. Попробуйте альтернативные RPC ноды:
   ```
   SOLANA_RPC_URL=https://solana-api.projectserum.com
   SOLANA_RPC_URL=https://rpc.ankr.com/solana
   ```
3. Используйте приватную RPC ноду (рекомендуется для production)

### 4. Недостаточно средств для транзакции

**Проблема**: "Недостаточно средств. Необходимо: X SOL"

**Решение**:
1. Проверьте баланс кошелька: `solana balance`
2. Пополните кошелек необходимой суммой SOL
3. Учтите комиссии сети (обычно 0.000005 SOL за транзакцию)

### 5. Транзакция не выполняется

**Проблема**: Бот сообщает об успешной покупке, но транзакция не появляется в блокчейне.

**Причина**: Текущая версия использует фиктивные транзакции для тестирования.

**Решение**: Для реальной торговли необходима интеграция с Raydium SDK.

### 6. Высокое использование RPC запросов

**Проблема**: Превышен лимит запросов к публичной RPC ноде.

**Решение**:
1. Используйте приватную RPC ноду
2. Увеличьте интервал между проверками в коде
3. Рекомендуемые провайдеры:
   - QuickNode: https://www.quicknode.com/
   - Alchemy: https://www.alchemy.com/

### 7. Проблемы с правами доступа к файлам

**Проблема**: Permission denied при создании или чтении файлов.

**Решение** (Linux/Mac):
```bash
chmod 600 .env
chmod 755 .
```

**Решение** (Windows):
- Запустите командную строку от имени администратора
- Проверьте права доступа к папке проекта

## Проверка безопасности

Запустите утилиту проверки безопасности:

```bash
node security-utils.js check
```

Эта команда проверит:
- Права доступа к .env файлу
- Наличие .env в .gitignore
- Отсутствие приватного ключа в конфигурационных файлах

## Диагностика

### Проверка окружения

```bash
# Проверка версии Node.js (требуется 14+)
node --version

# Проверка установленных зависимостей
npm list

# Проверка переменных окружения
node -e "console.log(process.env.SOLANA_PRIVATE_KEY ? 'Ключ найден' : 'Ключ не найден')"
```

### Тестирование подключения

```javascript
// test-connection.js
const { Connection } = require('@solana/web3.js');

async function testConnection() {
  try {
    const connection = new Connection('https://api.mainnet-beta.solana.com');
    const version = await connection.getVersion();
    console.log('Подключение успешно:', version);
  } catch (err) {
    console.error('Ошибка подключения:', err.message);
  }
}

testConnection();
```

### Логирование

Для детального логирования добавьте в .env:

```
DEBUG=true
LOG_LEVEL=debug
```

## Советы по оптимизации

### 1. Использование WebSocket

Вместо polling можно использовать WebSocket для мониторинга:

```javascript
connection.onProgramAccountChange(
  RAYDIUM_PROGRAM_ID,
  (accountInfo) => {
    // Обработка изменений
  }
);
```

### 2. Кэширование данных

Увеличьте TTL кэша для уменьшения нагрузки:

```javascript
this.poolsCacheTTL = 5 * 60 * 1000; // 5 минут
```

### 3. Batch запросы

Используйте batch запросы для получения данных:

```javascript
const accounts = await connection.getMultipleAccountsInfo(publicKeys);
```
